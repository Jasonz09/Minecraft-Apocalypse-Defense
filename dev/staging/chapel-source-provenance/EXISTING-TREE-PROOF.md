# Next existing read-only tree proof — no new adapter required

Use the existing developer diagnostic on the same completed city while no other
job runs, with the observer near the chapel:

`/scriptevent civ:generate_diag tree district=5 x=-214 y=69 z=-539`

This does not clear blocks. inspectSavedTree verifies the selected saved record,
then sharedTreeProtectionFor verifies every other completed protecting district,
matching dimensions and master plan, and compiles its tree safeguards. The current
closed snapshot has all five complete. Future changes during the native invocation
are not proved absent by this older adapter's source checks; it does not have the
room census's repeated raw-source/player guard. Do not present a lengthy run as a
single atomic source or native snapshot.

inspectNaturalTree creates an independent in-memory queue, indexes own final
blocks at dressing stage, obtains a bounded temporary chunk window (17-block
apron), and calls clearTree(session, seed, true). The inspectOnly return precedes
all write-ahead proof, progress saving and erasure. Its finally releases the
lease and ticking area; the command finally releases its job token. It changes
no blocks, saved plan or construction queue, but does request temporary engine
chunk loading, unlike the room census.

It follows one connected log structure (26-neighbor survey), with canopy leaf
paths bounded to six hops. Already planned tree parts are excluded. Bounds:
4,000 component cells, horizontal reach16, vertical reach40 from seed,32 tree
visits per slice and the normal1,500-read slice ceiling. Continuing log chains
beyond reach refuse and preserve the whole component; unloaded cells, persistent
leaves, foreign/unsafe contacts, saved-plan cells, protected clearance and unsafe
base can also refuse. The lowest collected log's base may be natural ground,
another log OR an exact final own-plan block. Therefore a pass does not prove an
unmodified root in original natural soil.

Actual output is only pass/refusal reason and collected cells/logs/leaves counts.
Some refusals include the first offending coordinate, material and boundary/base
reason. It does NOT return the whole adjacency graph, all log coordinates, root
list, full states, original topology or origin. Counts on an early refusal may
be partial. A pass uses the production maintenance heuristic, not ownership or
permission to erase the tree.

The broad treeNeighbourBenign insideFinishedDistrict exception and planned-ID
allowance remain part of that heuristic. Shared-wall proofs add more checks only
where that special margin path is used. This diagnostic is not a leaf-only room
policy, does not weaken protected cells, and must NOT be followed by a broad tree
writer just because it reports natural proof passes.
