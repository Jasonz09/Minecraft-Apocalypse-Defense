## Smallest safe next implementation sequence

1. **Normal authoring genesis and durable continuation, first.** Define a separate normal-city authoring profile on the existing activation/store/runtime, based on an actually witnessed root-created never-issued world with immutable closed backup and exact pack identity. No `fresh=true`, private pad certificate, arbitrary command descriptor, absence-only inference, played-city reset or v2 migration. Before construction, publish the existing intent/header/complete protocol; retain the genuine genesis receipt. Public code must later recognize the correct normal provenance and exact durable v3 epoch without keeping the private adapter's descriptor alive. Initial marker checks are activation provenance, not recurring permission that player departure can revoke.

2. **Explicit authoring HOLD, same loop, before any construction.** Because strict no-clock-reset is required, the reviewed authoring session must remain held AFTER successful activation until clean-starter handoff. Reuse `beforeStep` on the SAME loop; no new timer, fake hour, people command override or clock rewinding. Authoring HOLD must survive restart, fail closed for partial/future provenance, and block owner issuance. Keep people OFF. Existing builder jobs must continue through their own existing machinery while the simulation is held; verify this dependency before adopting the design. No claim that this hold already exists.

3. **Construct all five through the existing builder.** Preserve the exact activation/header and zero-issued inventory throughout real saved master/site/job publication, source checksums, construction pauses/rejoin and gate linking. Terrain surveys/protection remain the builder's authority; genesis says nothing about terrain suitability. Do not issue even a test actor in the source intended to ship as never-issued. Use disposable derivatives for lifecycle tests. Preserve all maintenance journals; if new construction needs wall/lighting reconciliation, add separate exact receipt-aware release checks rather than wipe receipts.

4. **Narrow no-reset arming for that proven source.** Add a separate validated transition, leaving legacy arming unchanged. Require full exact v3 namespace/inventory validation, `mode=fresh`, complete matching normal activation, issued0, chunks[], pendingnull, no orphan/future/v2 keys, actual witnessed never-issued chain, and the held source's complete canonical initial simulation fields. Preserve activation/header bytes and every authoritative receipt. Refuse an evolved kingdom rather than manufacture step0. A baseline comparison may verify all simulation fields after explicitly separating built geography; it must not replace the kingdom with `createInitialKingdom` and discard differences. Stamp release metadata only after fresh validation. Existing all-five/gates/plan/queue/farm checks remain mandatory. Crash or incomplete publication keeps the owner/hour held; no half-armed legacy fallback. Existing development-key cleanup is not atomic and needs explicit restart/fault semantics for this new transition.

5. **Public template handoff is a distinct contract.** Packaging needs an immutable source/export/pack digest chain and a reviewed normal continuation profile. Decide BEFORE implementation whether the never-issued authoring epoch is intentionally template-scoped and world-local, or each new template instance must mint a distinct epoch. Current fixed private epoch cannot silently answer that question. If minting per instance, define a genuine native clone identity/mint source and crash-safe transition without erasing source history; changing an ASCII epoch or trusting a copied marker is not a solution. If retaining a template epoch, explicitly prove no cross-world handle/tag authority and distinguish template authoring vs live instances. Exact archive self-hashing must avoid a circular descriptor/hash design. NULL-default legacy behavior remains unchanged for unrelated worlds; unknown v3 stays HOLD.

6. **Only then expose ordinary city cavalry.** Epoch-bound selection and public v3 capability dispatch through the same streets owner/death subscription, normal saved homes/anchors and shared cost2 quota. Do not ship the private pad's substituted homes/radius/selection. Selection changes must retain issued history and refuse unsafe fallback. This follows, rather than substitutes for, the normal genesis and starter contracts.
