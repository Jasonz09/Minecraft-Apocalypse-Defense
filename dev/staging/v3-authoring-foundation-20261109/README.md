STAGED ONLY. No runtime/main wiring, new owner/timer, native genesis adapter, trust descriptor or release permission. Existing private trials and public NULL behavior remain unchanged. Synthetic source DTOs in tests are deliberately NOT freshness certificates.

`createAuthoringHold` returns undefined by default with zero reads. Explicit opt-in supplies a callback for the existing loop that ALWAYS holds, including after activation and when evidence is malformed/unreadable. It never resumes, arms, rewinds, activates, or permits population. A later genuinely reviewed durable handoff must decide when the existing loop may resume; that implementation does not exist here.

`preparedAuthoringProblems` is a necessary refusal predicate only. It verifies an exact empty v3 header/census, matching completion fields and full canonical initial simulation while retaining built geography via the existing baseline helper. It never saves or returns a normalized replacement kingdom. Full genuine normal provenance/receipt validation, live source guards, all-five/gate/plan/job/farm release checks and restart-safe arming publication remain mandatory outside this helper. A fabricated `genuineGenesisReviewed` DTO is NOT authority. Private-pad source kind refuses.

Actual builder writes may change simulation logs or other fields. Such changes currently refuse preparation; this stage does not quietly discard them. Whether all-five native builds can complete under a held simulation remains an explicit next test. Public continuation and template-copy epoch semantics remain unresolved. This increment is intentionally not promotable as a complete release path.
