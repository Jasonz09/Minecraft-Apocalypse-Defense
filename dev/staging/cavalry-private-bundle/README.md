File-only preparation helper; no UI, install, process launch, Git operation or active-source change. It imports the already reviewed private-native-setup inventory function and emits that helper's existing bundle shape. It does not duplicate the paired installer or rollback machinery.

`node --check build.mjs` passes. **10/10 small tests pass (92.0703 ms)**. No generated directory exists at this checkpoint, no actual descriptor/profile was compiled, and no world was copied by this tool yet.

## Composition and output

The helper verifies current ordinary176+the exact3 startup-HOLD NULL paths against pinned baseline/source manifests. It refuses newer or changed active source instead of overwriting it. It overlays the immutable cavalry79 prerequisites, reviewed fresh-v3 stage, all5 exact cavalry data files and graph allowance evidence. Output is NEW stage/generated/<fixtureId> only, with no overwrite or deletion. Linked/escaping paths refuse. Every baseline/stage byte is checked again while copied. Failure leaves a started-but-incomplete directory for review and refuses reuse. The private output runs the pinned exact5-entity graph validator. This validates references, not Minecraft behavior.

Output contains private-packs/BP+RP, PRIVATE-PACK-PLAN.json, derivative-world, DERIVATIVE-PLAN.json and the compatible PROMOTION-HASHES.json. Only the derivative's two pack-binding lists change; all other source-world bytes remain exact. BUILD-COMPLETE.json is required before handing off; BUILD-STARTED remains historical evidence. Source witnesses/receipts and original world are preserved.
